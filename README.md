Portfolio - Kaick Silva

Site pessoal desenvolvido para apresentar minhas experiências profissionais, projetos acadêmicos e formas de contato. Construído do zero com HTML, CSS e JavaScript, com foco em um design moderno, responsivo e com boas práticas de front-end.

- Funcionalidades
  
Design responsivo (desktop, tablet e mobile)
Menu de navegação com scroll suave entre seções
Menu hambúrguer funcional para telas pequenas
Seção de experiências profissionais
Galeria de projetos com links para demo e repositório
Seção de contato com redirecionamento para e-mail e LinkedIn
Botão de download do currículo em PDF


Tecnologias utilizadas:

- HTML5
- CSS3 (Flexbox e Grid)
- JavaScript
- Font Awesome para ícones
